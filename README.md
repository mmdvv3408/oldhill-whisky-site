# Old Hill Spirits · scroll site

Static site, no build step. Open `index.html` through any static server (the clips are fetched, so `file://` will not work):

    npx http-server . -p 4500

Built with the scroll-craft engine (`scrollcraft.js` / `scrollcraft.css`, unmodified) and a design system from UI UX Pro Max.
See BRIEF.md for the journey and PLAN.md for the asset list.
